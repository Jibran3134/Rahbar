# P06: one-command Windows startup

Jibran asked for a single launch command instead of the individual infrastructure/testing steps. `run.cmd` calls scripts/start.ps1 and scripts/run_app.py. It checks installed prerequisites, prepares the Python environment/local minikube binary when absent, starts Docker Desktop and Ollama when necessary, pulls missing selected models, starts or reuses only the Rahbar profile, builds/applies on first deployment or -Rebuild, waits for rollouts, and opens localhost:8090. A loopback-only gateway supplies the Ingress host header, so normal browser use needs no hosts-file edit or manual forwarding.

Reuse startup was exercised through the real root command with -CheckOnly -NoBrowser: UI and API info returned HTTP 200, provider ollama-host, llama3.2:3b, nomic-embed-text/768 and a nonempty published real-corpus identity. See reuse-smoke.json. CheckOnly closes its own gateway and kubectl process; existing workloads/data/services remain. Current Kubernetes context remained k3d-civicpulse-ci.

Ten script tests passed (six existing, four new). New tests exercise actual HTTP forwarding of the Ingress Host, POST question/session body, HTTP error status and X-Cache/X-Request-ID; oversized-body rejection before forwarding; occupied-port rejection before touching services; and child-command failure propagation with visible diagnostics. Ruff passed. Initial testing caught Windows socket reuse bypassing the occupied-port check: exclusive address use now prevents it. PowerShell native argument quoting was corrected after a dependency-check expression lost inner quotes. Pytest temporary-directory access failed in the sandbox; the same tests passed with host access and a fresh workspace temporary directory. No test failure was hidden by a later successful command.

The existing user port-forward on 8085 was left alone; the launcher uses 8090. The real root `run.cmd -Rebuild -CheckOnly -NoBrowser` provisioning smoke passed: all three images built/loaded, resources applied, a new real indexing Job completed in 5m40s, API/UI rollouts passed and the localhost gateway returned the real UI/provider/index identity. See rebuild-smoke.json. A new bootstrap Job was necessary because the earlier completed Job had expired, while the existing active generation continued serving. Prerequisite OS installation (Docker Desktop/Linux containers, Git, kubectl, Ollama, Python 3.12) is still a one-time requirement. First-time Docker Desktop setup can request OS elevation.
