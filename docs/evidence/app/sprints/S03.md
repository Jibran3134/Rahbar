## Source fidelity issues found and corrected

### Clause numbering layout

Default Tesseract mode 3 detached left-margin numbering from paragraphs in two inspected scans. Mode 6 retained those associations. Evidence: S03-ocr-layout.json.

### Numeric OCR error

At 200 DPI, the source eligibility digit was recognized as a vertical bar. Tested 150/200/300 DPI against the original page: 150 and 300 recovered the actual digit; 200 failed that probe. Selected 300 DPI. There is no post-hoc replacement that invents the expected number.

Evidence: S03-ocr-resolution.json and the initial/final source-probe records.

### Invisible adjacent-page text

The handbook PDF retains glyphs at negative x coordinates outside the displayed page. On physical page 23, 1161/1991 character centers are outside the page. Raw extraction interleaved those invisible glyphs with the current withdrawal clause. The extractor now restricts text to the visible CropBox/bounds, verified by an owned synthetic red/green test and the original source.

This also corrected the S01 long-definition estimate: visible student-handbook page 48 has 237 whitespace words, while the earlier unclipped audit counted 314. docs/CORPUS.md explicitly records the correction; S01 historical audit observations remain retained. No golden answer/source/page was changed to flatter retrieval.

Evidence: S03-visible-page-audit.json.

### Final original-source probes

All six checks pass: historical extra-course clause, historical withdrawal deadline, scanned service-duration number, current extra-course clause, current withdrawal deadline and student AI-introduction section.

The final native corpus run was followed by check_source_probes against its saved outputs. The live audit CLI now includes these checks on future runs. The report records that follow-up execution explicitly; it does not pretend the earlier process loaded code added after it started.

These are extraction-fidelity checks, not recall@k, answer correctness, injection resistance or a complete OCR accuracy measurement.

## Meaningful table and unrecovered information

The real fee HTML table was compared against naive tag stripping. Extracted rows retain header/value boundaries, program pairing, units and effective-date context, with navigation removed. PIPELINE.md shows the short actual before/after representation.

No claim is made that unruled/multicolumn PDF tables, scanned annex cell relationships, handwriting or graphical signatures were reconstructed perfectly. OCR punctuation/spacing may still be wrong beyond inspected probes. These limits are documented rather than silently filled with invented facts.

HTML produces one logical page for the existing Page dataclass. Query/citation mapping must expose page=null for HTML; a logical page must not become a fabricated physical citation.
