Single-writer contract: every real writer must acquire the exclusive server collection lock. Forbid alone is insufficient. Crashed writers leave a stale lock, which intentionally blocks new writers. Operator must verify all indexer Jobs/local writers are stopped before explicitly deleting that exact lock. Never use time-based automatic expiry to steal it. The dummy starter path is a separate mode; never run it concurrently with real publishers. Lock release failures also require operator inspection.

Publication is one metadata-modify request plus readback, not a cross-collection transaction. If acknowledgement is lost after commit, the new validated generation may already be active: do not delete it or assume the previous pointer survived. Previous/failed collections are retained. Manual cleanup must exclude active/previous/in-flight generations and run only after readers/writers are quiescent; no automatic cleanup implemented.
