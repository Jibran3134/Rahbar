## Behaviors verified

- Missing optional environment keys preserve safe stub defaults; explicit blank/unknown selectors fail.
- Positive ports/counts/TTLs/timeouts and overlap < size are enforced. Direct dataclass construction/replacement cannot bypass the checks.
- Invalid numeric strings and NaN/infinity fail with the configuration key named.
- Endpoint parsing checks schemes/hosts/ports and unsupported URL components without connecting.
- Redis credentials and LLM key are hidden from repr; Redis parsing errors do not echo credentials.
- Both workloads read the same model/endpoint/collection settings; cross-workload tests compare overrides.
- Pure configuration tests forbid socket connect and still pass.
- Invalid startup configuration raises before retriever/provider factories initialize.
- Existing sessionless HTTP requests remain 200; invalid session IDs produce 422.
- Existing response fields remain present and reasoning stays absent.
- API and indexer active-index identities share exactly four wire fields, validate dimensions and are immutable.
- Failure categories are explicit; MAX_GENERATION_ATTEMPTS is fixed at 2.

No service/model live test is required for S02. Tests use in-process ASGI and pure configuration/data code. This sprint does not contact Chroma, Redis or Ollama.

## Session and publication wire contracts

AskRequest remains question-based with optional session_id. When present, ID must be a strict string of 1–128 characters, each ASCII letter, digit, underscore or hyphen. Null/omission means a standalone turn. AskResponse adds the same nullable optional field; the current service returns null because turn persistence/ID issuance are S12 work. Alishba should not claim working follow-up sessions from schema acceptance alone.

The Answer contract sent to the future model is unchanged. Reasoning is not added to the response.

ActiveIndex contains:

~~~json
{
  "collection": "rahbar-g1",
  "generation": "g1",
  "embed_model": "nomic-embed-text",
  "dimension": 768
}
~~~

Dimension 768 above is a shape-test example, not a live model measurement. Actual dimension must be measured in S06 and compared in S08. Identifiers are strict nonempty whitespace-free strings; dimension is a positive integer; API rejects extra identity keys. Publication/resolution is S07/S08 work, not implemented by creating these types.

Separate representations preserve independent Docker build contexts: indexer emits metadata; API Pydantic validates the exact four-field shape. A cross-workload test verifies compatibility. Existing chunk source/section/page/doc_version/superseded fields remain unchanged and original dummy metadata tests pass.

[Machine-readable schema/default export](S02-contracts.json) contains no configured secrets. [ADR 0004](../../../adr/0004-llm-provider-and-data-governance.md) records the compatible schema/provider decisions and pending review.

## Failure and retry contract

ProviderFailureKind values: timeout, transport, invalid_json, invalid_schema, invalid_citation. ProviderError carries the enum and a generic safe message; raw output/credentials are not constructor arguments.

MAX_GENERATION_ATTEMPTS = 2 means initial generation plus one validation retry. No retry loop, constrained provider call, fallback or timeout request handling was implemented here; S10/S11 consume these contracts. Selecting ollama-host is configuration-valid but its real generate function is still a later sprint.
