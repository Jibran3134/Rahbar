The original run was retained. Valid citations prove identity, not that a policy applies to the question. Passing an evaluator gate with many fallbacks does not establish useful-answer quality.

Automatic approval review initially rejected copying the live Secret to a new cluster because testing authorization did not cover the additional credential destination. Jibran then explicitly approved transferring **only LLM_API_KEY**. It was copied through in-memory subprocess stdin, never printed or written to a file. All three current-source Docker builds succeeded. Fresh public downloads all matched SHA-256. See evidence files for native outcomes; gitleaks native exit1 candidates were reviewed, not silently suppressed.

Known resource instability is not hidden: primary API and Chroma OOMKilled/137 last states were recorded before deliberate fault injection, during ordinary/pre-existing operation. This establishes inadequate demonstrated headroom, not the cause of every restart. A finite current-source load sample showed API/Chroma peaks within their configured limits and zero restarts; the older deployment’s OOM history is not attributed to current source without reproduction. A separate audit harness race selected a terminating pod; that first error is retained and the outage check was repeated with a stable pod.



The final exact-source native run is [fresh-sha-real-results.json](evidence/testing-audit-2026-11-07/fresh-sha-real-results.json); its native exit is 1.
